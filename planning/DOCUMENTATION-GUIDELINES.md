# Documentation Guidelines

## Purpose

This document defines the format and conventions used for project planning and documentation files.

The goal is to keep documentation:

- Simple and understandable
- Consistent across the project
- Easy to maintain
- Useful as a reference for developers and AI agents
- Clear about relationships between files and components

---

## File Header

Every planning or documentation file should begin with a short description of what the file contains.

Use this format:

```md
# File Name

> Briefly describe what this file documents and why it exists.

**Purpose:** Explain the specific purpose of this document.

**Related Files:**
- `path/to/file.md` — Briefly explain the relationship.
- `path/to/another-file.ts` — Briefly explain the relationship.
