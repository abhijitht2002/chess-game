# Chess Game

## About the Project

A chess game designed to provide a complete and interactive chess-playing experience.

The project includes both single-player and multiplayer gameplay, with features for playing against an AI opponent or another player.

## Built With

- TypeScript
- [![Next][Next.js]][Next-url]
- Tailwind css
- Node.js
- Express.js
- PostgreSQL

## Features

- Play against an AI opponent
- Play against other players online
- Real-time multiplayer gameplay
- Create and join games
- Automatic game state synchronization
- Player profiles
- Game history
- Responsive interface

## Game Modes

- Single Player: Play against the computer with AI-controlled gameplay.
- Multiplayer: Play against another player through an online multiplayer game.
